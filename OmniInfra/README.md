# OmniInfra

OmniInfra provides reusable infrastructure for building biomedical AI agents.
Our work focuses on the core components needed to connect language models,
biomedical tools, and scientific tasks in a consistent software framework.

## Our work

- Agent runtimes for planning, tool use, and multi-step execution
- Structured interfaces for biomedical tools and capabilities
- Model and retrieval components for scientific workflows
- Task abstractions for biomedical research applications

## Package

The core Python implementation is available in the `omniInfra` package directory.
